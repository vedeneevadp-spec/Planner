# Release notes

Этот документ хранит пользовательские заметки к релизам Chaotika. Его нужно
обновлять для каждого production rollout и для каждой публикации store build.

Пишите заметки так, чтобы их можно было почти без правки перенести в App Store,
Google Play, RuStore или в сообщение пользователям.

## Как вести

- В `Unreleased` собираются изменения, которые еще не ушли в production.
- Перед релизом перенесите пункты из `Unreleased` в новый раздел
  `vX.Y.Z - YYYY-MM-DD`.
- Укажите каналы релиза: `Web`, `PWA`, `iOS`, `Android`.
- Описывайте пользовательский эффект, а не внутреннюю реализацию.
- Breaking changes, ручные действия пользователя и ограничения выносите отдельно.
- Если изменение не заметно пользователю, но важно для поддержки, поместите его
  в `Техническое`.

## Unreleased

Нет невыпущенных пользовательских изменений.

## v1.1.34 - 2026-11-09

Каналы: Web, PWA, API

### API для своих скриптов и ботов

- В настройках появился раздел «API и интеграции». Создавайте отдельные ключи
  для своих скриптов, ботов и автоматизаций, выбирайте пространство, срок
  действия и разрешения на чтение или изменение.
- Через API можно получать, искать, создавать и изменять задачи и покупки,
  отмечать задачи выполненными, а покупки — купленными.
- Ключ показывается только при создании. В настройках видно его последнее
  использование; доступ интеграции можно остановить отзывом ключа.
- В разделе доступны документация и примеры для curl, Python, Node.js и n8n.

## v1.1.33 - 2026-11-05

Каналы: Web, PWA, Android (APK и обновление внутри приложения)

### Хаотика на Android — из чата в задачи, из браузера в покупки

Нажмите «Поделиться» у сообщения и выберите Хаотику. Откроется черновик задачи:

## v1.1.32 - 2026-11-05

Каналы: Web, PWA, Android (APK и обновление внутри приложения)

### Новое

- При редактировании задачи появилась кнопка «Оставить без даты». Она убирает
  дату, время и связанные напоминания, сохраняя остальные настройки задачи.
  Вернуть планирование можно кнопкой «Указать дату».
- AI-помощник видит задачи без даты отдельно от плана на день и неделю.
  Такие задачи не становятся просроченными и не увеличивают запланированную
  нагрузку.

### Исправления

- Поиск задач и история выполненного для AI работают и с большими списками.
  Если ответ содержит только часть записей, помощник получает информацию
  об этом и может продолжить просмотр задач.
- В AI-контексте точнее учитываются сроки, даты выполнения, покупки, уборка
  и забота. Разные задачи с одинаковыми названиями не объединяются,
  а задачи календаря не дублируют общие счётчики.
- История и прогресс заботы учитывают часовой пояс пользователя, в том числе
  на границе дня, недели и месяца.
- При медленной первой загрузке календарь открывается на утренних часах,
  как и при обычной загрузке. При первом перелистывании время не скачет.
- AI получает только разрешённые и запрошенные разделы планера.
- В общий Android-выпуск включены исправления 1.1.31: более надёжная
  офлайн-синхронизация при смене рабочего пространства и отправка напоминаний
  о заботе.

### Обновление

- На сайте и в PWA перезагрузите страницу. На Android установите новый APK
  поверх текущей версии или проверьте обновление в разделе «Ещё».

## v1.1.31 - 2026-11-05

Каналы: Web, PWA, Android (APK, личная доставка)

### Исправления

- Офлайн-синхронизация после переключения рабочего пространства не запускает
  одну очередь повторно параллельными запросами.
- Подготовка напоминаний о заботе больше не снимает блокировку уже отправляемого
  уведомления. Запоздалый ответ обработчика не меняет состояние новой отправки.

### Техническое

- Проверка зависимостей останавливается при ошибке `npm audit`, вместо сообщения
  об отсутствии уязвимостей без результата проверки.

### Обновление

- Установите полученный лично APK поверх текущей версии. Эта сборка не
  публикуется в общем Android-каталоге обновлений.

## v1.1.30 - 2026-11-05

Каналы: Web, PWA, Android (APK)

### Новое

  и проверки кода.

### Обновление

- Установите новый APK поверх текущей версии. В Хаотике 1.1.28 и новее
  обновление можно проверить в разделе «Ещё».
- Версия 1.1.29 использовалась для предварительной проверки. Этот выпуск
  обновляется и поверх неё.

## v1.1.28 - 2026-11-04

Каналы: Android (APK)

### Новое

- Хаотика предлагает обновиться прямо в приложении: «Обновить» скачивает APK
  и открывает системное подтверждение Android, «Позже» скрывает предложение
  на сутки. Проверить новую версию вручную можно в разделе «Ещё».
- Первый APK с этой возможностью нужно один раз установить привычным способом.
  После этого следующие версии можно получать внутри приложения.

### Обновление

- Установите APK поверх текущей версии. Приложение проверяет обновления
  автоматически; без новой версии или при отсутствии связи оно продолжает
  работать как обычно.
- Скачивание начинается после нажатия «Обновить». Если Android запросит
  разрешение на установку из Хаотики, разрешите его и подтвердите обновление.

## v1.1.27 - 2026-11-04

Каналы: Web, PWA, Android (APK)

### Новое

- Новые задачи по умолчанию создаются без даты. Они остаются в разделе
  «Актуальное» на экране «Сегодня» до выполнения и не требуют ежедневного
  переноса.
- Чтобы запланировать задачу, нажмите «Указать дату»: появятся обычные поля
  даты и времени. Все остальные настройки формы остаются на месте.
- При создании задачи из выбранного дня или времени в календаре этот выбор
  сохраняется. Задачи без даты не увеличивают запланированную нагрузку дня.

- В напоминаниях задач появились кнопки «Готово» и «Через 15 минут».
  Можно отметить дело выполненным прямо из уведомления. Без связи нажатие
  сохраняется и отправляется позже.
- Повторное напоминание не меняет дату задачи. В режиме энергосбережения
  Android может показать его позднее выбранных 15 минут.

### Исправлено

- Выполнение повторяющейся задачи без даты больше не добавляет ей
  непредусмотренный срок.

### Обновление

- Для сайта и PWA перезагрузите страницу. На Android установите новый APK
  поверх предыдущей версии: данные и настройки сохранятся.
- Кнопки действий в уведомлениях доступны на Android после обновления APK.

## Поиск и перенос задач - 2026-11-03

Каналы: Web, PWA

### Новое

- В верхней панели появился общий поиск по задачам, покупкам, уборке и заботе.
  Он ищет по названиям и заметкам, позволяет включать выполненные записи
  и открывать подробности найденного.
- В антиперегрузе можно подобрать день для задачи на неделю вперёд.
  Перед переносом видна нагрузка до и после с учётом повторяющихся задач
  и срока. Перенос требует подтверждения; после него доступна отмена.
- Если данных о нагрузке недостаточно, день отмечается как неполностью
  оценённый. Поиск при потере сети ждёт подключения и продолжает работу
  после восстановления связи.

### Исправлено

- Устранена редкая ошибка первого входа при одновременной регистрации
  нескольких пользователей. Существующие личные пространства сохраняются.

### Обновление

- Для обновления сайта и PWA перезагрузите страницу.
- В установленном приложении новый интерфейс появится с отдельным
  обновлением приложения.

## v1.1.24 - 2026-10-29

Каналы: Web, PWA, Android

### Новое

- Повторяющиеся заботы теперь можно поставить на паузу. Они перестают

  обновления остаются доступны.

## v1.1.23 - 2026-10-25

Каналы: Web, PWA, Android

### Исправлено

- Разные названия часовых поясов с одинаковым текущим временем больше не

Каналы: Web, PWA, Android (личная сборка)

## v1.1.22 - 2026-10-08

Каналы: Web, PWA, Android

### Новое

- В недельном календаре можно создать задачу нажатием на свободную часовую
  ячейку. Дата и время начала уже заполнены; выбранный день сохраняется даже
  для прошедшего времени. Перелистывание недель свайпом продолжает работать.

### Исправлено

- Выполненная задача на главном экране больше не возвращается на короткое
  время при фоновом обновлении списка.
- Список покупок больше не сдвигается при сохранении изменений. Сообщение о
  проблеме с сетью появляется после неудачной попытки связи как всплывающее
  уведомление; его можно закрыть или повторить синхронизацию.
- Русскоязычные сферы создаются последовательно без ошибки; сбой загрузки или
  сохранения можно повторить без потери введённых данных.
- Редактирование задач сохраняет время, месячный ритм повторов и выбранную
  сферу. Календарь использует часовой пояс планера и показывает в неделе задачи
  без времени.
- Изменение расписания уборки обновляет ближайший срок. Он виден до сохранения;
  ручные переносы сохраняются.
- Повторная покупка учитывает выбранную категорию. Мобильные фильтры получили
  понятные названия для программ экранного доступа.
- История заботы показывает правильный местный день и позволяет открыть более
  ранние периоды.
- Восстановление пароля доступно сразу при входе. Из просроченной ссылки можно
  запросить новую; сохранённая сессия больше не закрывает форму восстановления.

### Техническое

- Обновлены библиотеки веб-приложения, сервера и мобильной оболочки, включая
  исправления безопасности.

### Обновление

- В браузере и PWA обновите страницу. Для Android установите новую версию
  приложения.
