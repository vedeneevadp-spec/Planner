# Выпуск Chaotika 1.1.20

Выпуск разрешён пользователем 18 сентября 2026 года после отчёта о реализации.
Android: versionName 1.1.20, versionCode 28; iOS metadata: 1.1.20 / 28.
Каналы: Web, PWA, подписанный Android APK. Публикация в магазинах и отправка
внешних сообщений выполняются только при отдельном разрешении.

## Исходники и границы выпуска

Основа — production/main `e9bd10e47bd6534e7ed12f8593072ca8a4155215`.
В отдельную ветку перенесены только изменения удаления встроенного голосового
ввода. 17 файлов с отдельными локальными изменениями интерфейса задач и
аудитами из HEAD `2b40273` в выпуск не включены. Исходное рабочее дерево
сохранено. В чистом релизном checkout TodayPage проходит 83/83 теста;
устаревшие ошибки локального baseline к этому состоянию не относятся.

## Два состояния выпуска

- A: новый совместимый код и схема до 000105; файлов 000106/000107 нет.
- B: тот же код плюс 000106/000107. Развёртывается после подтверждения A
  во всех API/worker/restore процессах. A остаётся безопасной точкой отката.

Подробная последовательность и ограничения:
[release-plan.md](release-plan.md). Для каждого состояния требуются отдельные
проверки, commit/ref, PR и штатный guarded deploy.

## Проверка перед выпуском

Локальный полный CI состояния A прошёл: 1218 web-тестов, 369 API-тестов,
coverage, lint, types, OpenAPI и build budgets. На старой схеме прошли
94 PostgreSQL-теста, 21 E2E-сценарий и mobile-auth gate. Для состояния B
прошли 96 PostgreSQL-тестов без пропусков, включая fresh/upgrade миграции
и OAuth; в GitHub CI эти два теста включены для PostgreSQL 17 и 18 через
отдельную тестовую БД.

Production на начало выпуска здоров: API, reminder worker и restore helper
активны на исходном main. Перед выпуском снята offsite-копия
`planner-infra-2026-09-18T09-18-42-693Z`; восстановление в отдельном recovery
cluster успешно, invalid constraints 0, временные БД удалены. Этот первый
drill проверяет цепочку до 000105; проверка того же backup с 000106/000107
выполняется отдельно перед B.

Подпись Android проверена на совпадение с ранее выпущенным 1.1.19 / 27.
Проверка обновления на телефоне пока не выполнена: USB-отладка требует
подтверждения на подключённом устройстве.

Итоговые SHA, PR, backup, результаты deploy и метаданные подписанного APK
фиксируются после завершения соответствующих операций. Этот документ сам
по себе не подтверждает завершение production rollout.
