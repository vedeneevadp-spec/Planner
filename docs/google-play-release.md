# Первый выпуск Chaotika в Google Play

## Сборка

Идентификатор приложения: `ru.chaotika.app`. Сохранять существующий ключ
подписи для совместимости с установленными APK. В Play App Signing нужно
использовать копию существующего app signing key; upload key можно отделить.
Не менять applicationId ради карточки магазина с другим именем пакета.

```bash
npm run mobile:release:google-play -- --api-url=https://chaotika.ru --version=1.1.36 --build=44
```

Команда собирает подписанный AAB с каналом `googlePlay`, проверяет production
API, включает обычную авторизацию и проверяет готовый архив. Выход:
`android/app/build/outputs/bundle/release/app-release.aab`.

В Google Play release исключены Java-классы `PlannerAppUpdate*`, регистрация
их Capacitor-плагина, web-модуль внешнего обновления и разрешение
`REQUEST_INSTALL_PACKAGES`. Обычные команды APK/RuStore используют канал
`direct` и сохраняют обновления с сервера. Разделение выполняется при сборке,
не по определению установщика на устройстве. Для ручного вызова Gradle
необходимо синхронно собрать web с `VITE_ANDROID_DISTRIBUTION=googlePlay`
и передать `-PdistributionChannel=googlePlay`; предпочтительнее единая команда.

Проверка артефакта входит в release-команду; отдельно:

```bash
node --input-type=module -e "import {assertGooglePlayArtifact} from './scripts/google-play-artifact.mjs'; await assertGooglePlayArtifact('android/app/build/outputs/bundle/release/app-release.aab')"
```

## Карточка магазина

- Название: **Chaotika — планер жизни**.
- Стандартный язык: русский (`ru-RU`).
- Тип: приложение; категория: продуктивность / работа.
- Модель текущего выпуска: бесплатно, без рекламы и встроенных покупок.
- Контакт: `support@chaotika.ru`; сайт: `https://chaotika.ru`.
- Политика: `https://chaotika.ru/privacy.html`.
- Запрос удаления: `https://chaotika.ru/delete-account.html`.
- Иконка: `apps/web/public/icons/icon-512.png`.
- Графика: 1024 × 500; телефонные скриншоты: 720 × 1280, демонстрационные
  данные без личных сведений пользователя.

Краткое описание (до 80 символов):

> Задачи, покупки, домашние дела и забота о себе — в одном спокойном планере.

Полное описание:

> Chaotika помогает собрать повседневные дела в одном месте и планировать
> день с учётом своих сил.
>
> ЗАДАЧИ И ПЛАНЫ
>
> Записывайте задачи на сегодня, на будущее или без даты. Добавляйте сроки,
> напоминания, повторения и подзадачи. Смотрите планы в календаре, находите
> нужные записи поиском и распределяйте дела по сферам жизни и проектам.
>
> ПОКУПКИ И ДОМ
>
> Ведите списки покупок, сохраняйте ссылки на товары и отмечайте купленное.
> Планируйте уборку и домашние рутины. Делитесь пространством с близкими,
> чтобы видеть общие дела.
>
> ЗАБОТА О СЕБЕ
>
> Планируйте отдых, движение и личные ритуалы. По желанию записывайте
> настроение, энергию и самочувствие, чтобы замечать собственный ритм.
>
> ПОД РУКОЙ НА ANDROID
>
> Добавляйте задачи и ссылки через меню «Поделиться», используйте виджеты
> и push-напоминания. Изменения, сделанные без сети в поддерживаемых
> разделах, синхронизируются после восстановления соединения.
>
> Для синхронизации нужен аккаунт. Также доступна веб-версия chaotika.ru.
> В текущей версии нет рекламы и платных подписок.
>
> Chaotika не является медицинским устройством и не предназначена для
> диагностики, лечения, излечения или предотвращения заболеваний.
> За медицинскими рекомендациями, диагностикой и лечением обращайтесь
> к квалифицированному специалисту.

## Декларации: проверенная основа для заполнения

Это описание фактической обработки данных в текущем коде, а не экспорт
заполненной формы Play Console. Каждый вопрос нужно сверить с формулировкой
консоли перед отправкой. Независимая сертификация безопасности не заявляется.

| Тип данных                            | Основание                                                  | Цель / обязательность                                                             |
| ------------------------------------- | ---------------------------------------------------------- | --------------------------------------------------------------------------------- |
| Имя, email, user ID                   | Регистрация и профиль                                      | Управление аккаунтом, работа приложения; обязательные для аккаунта                |
| Фото                                  | Пользовательский аватар                                    | Работа приложения; по желанию                                                     |
| Другой пользовательский контент       | Задачи, заметки, списки, домашние дела, общие пространства | Работа и синхронизация; пользователь решает, что вводить                          |
| Календарь                             | Даты задач и явно переданное событие Android               | Планирование; по желанию; прямого доступа к календарям устройства нет             |
| История покупок                       | Записи о купленных товарах                                 | Работа списка покупок; по желанию; платежи не обрабатываются                      |
| Сведения о здоровье                   | Настроение, сон, стресс, боль, измерения в заботе          | Личная история и планирование; по желанию                                         |
| Физическая активность                 | Введённые упражнения и подходы                             | Личная история и планирование; по желанию                                         |
| Идентификаторы устройства / установки | FCM/Firebase Installations, device session ID              | Уведомления, работа приложения, безопасность; FID может создаваться автоматически |
| Действия в приложении                 | История выполнения и изменения записей, API/MCP audit      | Работа приложения и безопасность                                                  |
| Диагностика                           | Технические ошибки и серверные журналы                     | Работа приложения и устранение ошибок                                             |

- Данные собираются: да; серверная синхронизация — это сбор, даже без рекламы.
- Данные передаются по HTTPS. Сквозное шифрование не заявлять.
- Удаление аккаунта и данных доступно в профиле и через публичную страницу.
- Нет рекламы, рекламного ID, SDK аналитики, Health Connect, чтения контактов,
  SMS, микрофона или геолокации. IP используется для безопасности, а не для
  определения местоположения.
- Передача поставщикам инфраструктуры и FCM для обслуживания, а также
  инициированная пользователем передача участникам пространства/интеграциям,
  может подпадать под исключения из «sharing». Сверить условия исключений
  Google перед ответом, не считать наличие Firebase автоматически рекламой.
- Обязательно заполнить Health apps declaration: есть функции самочувствия
  и упражнений. Это общий планер с функциями заботы; медицинская диагностика,
  лечение, исследования и подключение медицинских устройств отсутствуют.
- Возрастная аудитория, страны и итоговый IARC-рейтинг выбираются отдельно;
  рейтинг не выдумывать до прохождения анкеты.

## Доступ проверяющим

Нужен отдельный аккаунт с демонстрационными задачами и покупками, без данных
владельца. Email и пароль хранить вне Git. Перед отправкой проверить вход в
точной магазинной сборке. Инструкция для проверяющего:

> Войдите с предоставленными email и паролем. Откройте «Сегодня», создайте
> задачу, перенесите её на завтра и отметьте выполненной. В «Покупках»
> добавьте товар и отметьте его купленным. В «Ещё → Профиль» доступны
> настройки профиля и удаление аккаунта. Для создания нового тестового
> аккаунта доступна регистрация по email и паролю; подтверждение email
> и двухфакторный код не требуются.

## Закрытый тест

Новый личный аккаунт требует минимум 12 участников, непрерывно подключённых
к закрытому тесту не менее 14 дней. Внутренний тест не заменяет закрытый.
Список email сам по себе не означает, что люди подключились. Перед заявкой
нужны реальные результаты использования и исправления по обратной связи.

Текст приглашения (ссылку добавить после создания тестового выпуска):

> Тестирую Chaotika — планер задач, покупок и домашних дел для Android.
> Нужна помощь с закрытым тестом Google Play: подключиться по ссылке,
> установить приложение из магазина и попробовать его в обычных делах
> в течение двух недель. Пожалуйста, не выходите из теста 14 дней подряд.
> Попробуйте создать и завершить задачу, перенести её, составить список
> покупок и настроить напоминание. Если что-то неудобно или не работает,
> напишите модель телефона, что делали и что произошло. Для добавления
> в тест нужен адрес Google-аккаунта, используемого в Play Маркете.

Приглашение подготовлено для владельца; автоматически никому не отправлять.
После теста заявку на доступ к production заполнять только по фактическим
результатам. Не обещать публикацию через ровно 14 дней.
