### B01 · P1 · Вторая русскоязычная сфера подряд не создаётся

**Воспроизведение:** создать «Здоровье аудит», затем через несколько секунд «Работа аудит» в том же пространстве.

**Факт:** первый POST → 201, второй → 500. Форма остаётся открытой без объяснения ошибки. PostgreSQL сообщает конфликт `projects_workspace_id_slug_key`.

**Причина:** [генератор slug](</Users/daryavedeneeva/ Projects  /Planner/apps/api/src/modules/life-spheres/life-sphere.shared.ts:23>) удаляет кириллицу, получает `sphere` и добавляет первые 8 символов UUIDv7. Это старшая часть времени; она одинакова внутри одного интервала около 65,5 секунды. Два разных русских названия получают одинаковый slug. Граница временного интервала может сделать проблему непостоянной.

**Исправление и приёмка:** использовать уникальный идентификатор целиком или его действительно уникальную часть; показывать ошибку сохранения непосредственно в форме. Создание нескольких разных русских названий подряд и параллельно завершается успешно, все записи остаются после reload. Ошибка сервера видна и допускает повтор.

**Подтверждение:** реальный UI и PostgreSQL; [запросы и ответы](</Users/daryavedeneeva/ Projects  /Planner/tmp/user-scenario-audit-20260922/account/russian-spheres-results.json>), [скриншот формы](</Users/daryavedeneeva/ Projects  /Planner/tmp/user-scenario-audit-20260922/account/russian-sphere-create-failure.png>).

## Границы результата

- Production, реальные аккаунты, физические Android/iOS устройства, реальная доставка email/push и системные ограничения фоновых уведомлений не тестировались. Мобильные auth E2E работают с эмуляцией native-моста; их результат не заменяет проверку установленного APK.
- Реальная многопользовательская гонка редактирования одной записи и длительные сетевые разрывы здесь полностью не покрыты. Штатный сценарий общего пространства пройден.
- HTTP 500 сферы моделировался намеренно. Исторические даты и UTC-пограничные записи создавались в синтетической базе. Перечисленные ошибки сохранения задач воспроизведены настоящими UI-запросами к PostgreSQL.
- Дополнительные 3 диагностических DOM/model-теста задач, 47 API и 120 web тестов бытовых разделов поддерживают выводы, но пересекаются с общими suite; они не прибавлены к общим числам.
- В `tasks/browser-proofs.json` финальный timeout относится к ожиданию видимости линии времени нулевой высоты после успешно проверенных трёх редактирований. Отдельная проверка `marker-proof.json` успешно измерила эту линию. Это ограничение диагностического скрипта, не отдельный баг приложения.
- Все ссылки на доказательства относятся к локальным артефактам. Снимки состояния авторизации и токены в папки доказательств не копировались.
