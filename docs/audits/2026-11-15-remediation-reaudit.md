## Дополнительные исправления повторного аудита

- **Иконки:** повторный logical asset ID больше не перезаписывает существующий файл до проверки БД. Имя содержит случайный UUID, запись выполняется с `wx`; регрессия проверяет сохранность исходных байтов.
- **Выход из аккаунта:** поздний refresh/read/sign-in не возвращает завершённую сессию. Контроллер проверяет поколение операции; отзыв на сервере не ждёт offline cleanup. JS, iOS и Android сохраняют признак выхода, Android widget и plugin используют общую блокировку. Проверены отказ native удаления, переполнение/недоступность localStorage, повторный вход и отсутствие зависания bootstrap.
- **Проверяемость:** CI запускает собранный API только с production-зависимостями под непривилегированным DB login, Swift regression и Android instrumentation. Добавлен production PWA smoke. Actions закреплены по проверенным SHA, permissions ограничены, smoke credentials случайные с cleanup, добавлен SECURITY.md.
- **Стартовая загрузка:** окно участников загружается только при открытии. Initial JS уменьшен с 796,1 до 789,3 КБ; прежний бюджет 790 КБ проходит. Отдельно проверены загрузочное окно, отмена и настоящий браузерный сценарий участников.
- **Инструменты:** npm приведён к требуемой версии 12.2.2. Новые production-зависимости не добавлены.

## Изменения архитектуры и оставшийся техдолг

Выполнен направленный рефакторинг: общий authenticator для Алисы, атомарная операция MCP, общие lifecycle/locking/deadline утилиты, единая граница модальных окон, отдельные snapshot и credential helpers для backup, независимые commit и файловая очистка. Эти изменения закрывают конкретные ошибки на границах подсистем.

Остаются рекомендации первичного аудита: разделение крупных self-care/AI-context/deploy модулей, окончательное удаление legacy habits после решения судьбы старых данных, SQL-пагинация поиска после измерений и сокращение стартовой загрузки. Сам размер файла не доказывает ошибку. Проект не объявляется свободным от всего технического долга.

Ограничения и осознанные решения:

- Защита A03 управляет клиентской очередью и обычными неопределёнными результатами. В серверном протоколе нет workspace epoch, поэтому нельзя обещать глобальный порядок любых ранее отправленных запросов между всеми клиентами. Для такой гарантии нужен отдельный контракт поколений восстановления на сервере.
- После ошибки БД с неизвестным исходом файл сохраняется. Возможны неиспользуемые загрузки; их будущая уборка должна сверяться с БД и действующими backup, чтобы не удалять актуальный ресурс.
- Backup при исчезнувшем файле завершается ошибкой, сохраняя предыдущую успешную копию. Исправление обеспечивает достоверность успешного результата, а не отсутствие любых неуспешных запусков.
- MCP refresh одноразовый: повтор уже выполненного обмена отклоняется. Если клиент потерял успешный ответ, ему потребуется повторная авторизация; автоматическое восстановление этой OAuth-сессии не добавлялось.
- iOS full build не выполнен: локальный Xcode не загружает IDESimulatorFoundation из-за несовместимого символа DVTDownloads. Это ошибка среды до компиляции приложения. Physical iOS/Android и выполнение instrumentation на устройстве не проверены; локальных AVD и подключённых устройств нет.
- Production env, реальная доставка SMTP/Google/Yandex/FCM, offsite repository и disaster recovery не проверялись. Изменения workflow ещё не исполнялись на GitHub для этой ветки; удалённые alerts не объявляются закрытыми.

## Применение

Основные группы изменённых файлов:

- Auth/API: `apps/api/src/modules/auth/email-verification.*`, `alice.routes.ts`, `mcp-haotika.auth.ts`, `session.service.ts`, миграции 115–118 и новые регрессионные тесты.
- Web: `shared/lib/offline-sync`, общий `api-client`, shopping/habit stores и drains, `ModalSurface`, `LazyWorkspaceParticipantsDialog`, `EmailVerificationPanel`, service worker и auth controller/storage.
- Native: `ios/App/App/AppDelegate.swift`, новый `PlannerAuthSessionRotation.swift`, Android auth plugin/widget storage и instrumentation-тесты.
- Инфраструктура: backup/restore/credentials/snapshot helpers, production API и PWA smoke scripts, `.github/workflows`, `docker-compose.yml`, `SECURITY.md` и runbook.

Для выпуска нужны миграции `20261115_000115`–`000118`, обновление API/web и native-сборок. Миграции применялись только к одноразовым тестовым БД. Dev PostgreSQL изменён только по привязке порта, его пользовательский том сохранён.

Старые аккаунты автоматически подтверждаются только при наличии доказательства Google identity или успешно использованного восстановления пароля. Остальным доступно подтверждение из профиля; существующие memberships не удаляются. SMTP использует существующую конфигурацию почты приложения.

Изменения находятся в рабочем дереве, без публикации и deployment. Одноразовый контейнер с тестовыми БД остановлен и удалён после проверок. [Первичный отчёт](2026-11-15-full-project-audit.md) сохраняет исходные находки; этот документ фиксирует результат исправлений и границы повторной проверки.
