# Проверка полноты выпуска 1.1.21

18 сентября 2026 года. Проверено относительно production/main
`8a61af4a1f3dfab3cac27b6cd2e09336048d3e3c`.

## Подтверждённый пропуск

В 1.1.20 не вошёл локальный коммит
`2b40273eca2238e5ae7b89b0b514f00825b45676`
(`fix: simplify task resource UI and add audit reports`). При подготовке
прошлого релиза он был ошибочно исключён из состава выпуска.

В 1.1.21 весь коммит перенесён через `cherry-pick -x`: все 17 файлов,
2234 добавленные и 92 удалённые строки. Включены упрощённый ResourcePicker,
нейтральный ресурс формы по умолчанию, удаление счётчика из ResourcePlanPanel,
соответствующие component/E2E tests и шесть ранее локальных audit documents.

  `12782cf` уже входят в production через PR #149, несмотря на другие SHA

- Выполнено сравнение Git blob hashes всех tracked и non-ignored untracked
  файлов исходного рабочего дерева с production плюс `2b40273`.
  **1219 файлов совпадают.** Других пропущенных продуктовых изменений нет.
- Шесть оставшихся различий относятся к более новым данным выпуска:

  Локальные личные конфигурации, ignored datasets и APK не переносились
  в tracked исходники; исходное рабочее дерево и история сохранены.

Проверка охватывает текущую рабочую ветку, её незакоммиченные исходники и
недавние локальные release branches. Неслитые экспериментальные ветки и
открытые Renovate PR не считаются потерянными изменениями этого выпуска.

Во время проверки релиза в `main` отдельно вошёл PR #153,
`e76f1563479f84c19e8416246ecbaec75895fdca` с patch updates существующих
зависимостей. Release branch синхронизирована с этим коммитом;
обновлённые manifests/lockfile сохранены. В частности, Fastify 5.12.4,
JOSE 6.2.12 и Dexie 4.4.6 входят в итоговый набор зависимостей.

## Сопутствующая проверка тестов

В TodayPage.test.tsx оставались 16 параметризованных случаев из семи
определений тестов, ожидавших удалённую коммитом строку «Оценено…».
Assertions приведены к новому UI: раскрытие панели, полнота данных,
нагрузка и лимит. Runtime сверх запрошенного коммита не менялся.
Инварианты неполной загрузки, offline/cache, даты/часового пояса,
успешного refresh и независимости от ошибок self-care сохранены.

Первый E2E-прогон на новой пустой БД: 20/21. Единственный сбой произошёл
до проверки интерфейса при одновременной первичной регистрации: PostgreSQL
зафиксировал конфликт `users_single_owner_idx` для `app_role=owner`,
который существующий auth repository представил как занятый email.
Это отдельная проблема первоначального создания владельца, а не изменение
ResourcePicker. Диагностические trace и DB log сохранены в материалах
выпуска. Повторный полный прогон после создания первого владельца:
**21/21 passed**, без изменений auth runtime или E2E-тестов.

Новых SQL-миграций или production dependencies нет. Релиз использует
обычный guarded deploy поверх уже совместимой схемы 000107.
